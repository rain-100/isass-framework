# isass-framework-v4 V3 架构与完整调用链分析

> 基于 V2 架构升级，全面阐述 V3 统一 Controller、去 DbEntity、泛型推断、表元数据自动注册等核心改进。

---

## 一、v3 vs v2 核心差异

| 维度 | v2 | v3 |
|------|----|----|
| Controller | 每实体一个（`IV2Controller`） | 统一一个（`V3Controller`），36 端点 |
| 路由 | `/{serviceName}/{entityName}/v2/...` | `/{serviceName}/{entityName}/v3/...` |
| API 文档 | N×36 条 | ~36 条 |
| 服务发现 | `@Autowired` 固定注入 | `V3ServiceRegistry` 按 entityName 映射 |
| 服务名 | Service 接口常量硬编码 | `IV3Service.serviceName()` 从实体包路径推断 |
| Entity 名 | 类名推断 | `IV3Service.entityName()` 从泛型 E 推断 |
| Criteria | `@ModelAttribute` 绑定具体类 | `@RequestParam Map` + `V3CriteriaMapper` 反射转换 |
| ORM | Entity + DbEntity(@TableName) + Convert | Entity 直接操作 MyBatis-Plus，`V3TableMetaRegistrar` 启动时注册元数据 |
| 代码生成 | 10 文件（含 entityDb + controller） | 8 文件（删 entityDb + controller） |

## 二、v3 分层架构

```
┌────────────────────────────────────────────────────────────┐
│  外部 HTTP 请求                                              │
│  GET/POST/PUT/DELETE /{serviceName}/v3/{entityName}/...    │
└──────────────────────┬─────────────────────────────────────┘
                       │
┌──────────────────────▼─────────────────────────────────────┐
│  Layer 1: V3Controller (class)             [nocode-core]   │
│  - 统一 Controller，36 端点                                   │
│  - V3ServiceRegistry.require(serviceName, entityName)      │
│  - V3CriteriaMapper: Map<String,String> → Criteria 对象     │
└──────────────────────┬─────────────────────────────────────┘
                       │ service.xxx(params)
┌──────────────────────▼─────────────────────────────────────┐
│  Layer 2: IV3ServiceManager             [nocode-core]      │
│  - 路由层，遍历 services 列表                                 │
│  - V3ServiceManagerUtil.applyUntilNotNull()                │
└──────────────────────┬─────────────────────────────────────┘
                       │
┌──────────────────────▼─────────────────────────────────────┐
│  Layer 3: IV3LocalService               [nocode-core]      │
│  - 默认实现委托给 IV3Repository                              │
└──────────────────────┬─────────────────────────────────────┘
                       │ getRepository()
┌──────────────────────▼─────────────────────────────────────┐
│  Layer 4: IV3Repository                [nocode-core]       │
│  - 数据访问接口                                              │
└──────────────────────┬─────────────────────────────────────┘
                       │ implements
┌──────────────────────▼─────────────────────────────────────┐
│  Layer 5: V3MybatisPlusRepository      [nocode-core]       │
│  - extends ServiceImpl<M, E>                               │
│  - Entity 直接作为 MyBatis-Plus 实体（无 DbEntity 层）       │
│  - V3WrapperUtil 转换 Criteria → Wrapper                    │
│  - 无 Entity↔EDB 转换，零 Convert 开销                       │
└────────────────────────────────────────────────────────────┘
```

### 2.1 模块职责

| 模块 | 职责 |
|------|------|
| `isass-nocode-core` | **nocode 整合层**：V3 全部接口+实现+Controller+ORM+生成器，业务唯一入口 |
| `isass-web-springmvc` | MVC 基础设施（拦截器、异常处理等） |
| `isass-database-mybatisplus` | ORM 基础设施（Mapper、TypeHandler 等） |

## 三、核心类

### 3.1 V3Controller — 统一控制器

**文件位置：** `isass-nocode-core/src/main/java/vip/isass/framework/nocode/v3/controller/V3Controller.java`

```java
@RestController
public class V3Controller {

    private final V3ServiceRegistry serviceRegistry;
    private final V3CriteriaMapper criteriaMapper;

    // 36 端点方法，URL 模式 /{serviceName}/{entityName}/v3/...
    @GetMapping("/{serviceName}/{entityName}" + IV3Service.FIND_BY_CRITERIA_URI_SECOND_PART)
    public List<?> findByCriteria(@PathVariable String serviceName,
                                   @PathVariable String entityName,
                                   @RequestParam Map<String, String> params) {
        IV3Service<?, ?> service = serviceRegistry.require(serviceName, entityName);
        Object criteria = criteriaMapper.toCriteria(params, (Class) service.criteriaClass());
        return service.findByCriteria(criteria);
    }
    // ... 其余 35 个方法
}
```

### 3.2 V3ServiceRegistry — 服务注册表

**文件位置：** `isass-nocode-core/src/main/java/vip/isass/framework/nocode/v3/V3ServiceRegistry.java`

启动时扫描所有 `IV3Service` Bean，构建 `entityName → IV3Service` 映射。`require()` 校验 entityName 存在且 serviceName 匹配，否则返回 404。

### 3.3 V3CriteriaMapper — 参数转换

**文件位置：** `isass-nocode-core/src/main/java/vip/isass/framework/nocode/v3/V3CriteriaMapper.java`

`Map<String,String>` → Criteria 对象的反射转换。按参数名匹配 Criteria 的链式 setter，支持 String/Long/Integer/Boolean 类型自动转换。

### 3.4 IV3Service — 元数据推断

**文件位置：** `isass-nocode-core/src/main/java/vip/isass/framework/nocode/v3/service/IV3Service.java`

从泛型参数 `<E, C>` + 实体包路径推断所有元数据：

```java
default Class<E> entityClass()    { return serviceTypeArgs()[0]; }  // 泛型 E
default Class<C> criteriaClass()  { return serviceTypeArgs()[1]; }  // 泛型 C  
default String entityName()       { return "V3Icon" → "icon"; }     // 类名推断
default String serviceName()      { return "attachment-service"; }  // 包路径推断
```

### 3.5 V3TableMetaRegistrar — 表元数据注册

**文件位置：** `isass-nocode-core/src/main/java/vip/isass/framework/nocode/v3/V3TableMetaRegistrar.java`

遍历 IV3Service，从实体实现的 IV3* 接口推断 ORM 配置：

| 检测接口 | 推断配置 |
|---------|---------|
| `IV3IdEntity` | tableName、idType=ASSIGN_ID、keyType |
| `IV3TraceEntity` | 6 个追踪字段 fill INSERT/INSERT_UPDATE |
| `IV3LogicDeleteEntity` | deleteFlag = @TableLogic |
| `IV3VersionEntity` | version = @Version |
| `IV3TenantEntity` | tenantId 列名 |
| `IV3ParentIdEntity` | parentId 列名 |

### 3.6 V3TablePrefixUtil — 表前缀

**文件位置：** `isass-nocode-core/src/main/java/vip/isass/framework/nocode/v3/V3TablePrefixUtil.java`

静态工具，各模块 DB 配置类在初始化时注册：

```java
// AttachmentDbAutoConfiguration
@PostConstruct void init() {
    V3TablePrefixUtil.register("attachment-service", "att_");
}
```

### 3.7 IV3Entity.tableName() — 自定义表名

**文件位置：** `isass-nocode-core/src/main/java/vip/isass/framework/nocode/v3/entity/IV3Entity.java`

```java
default String tableName() { return ""; }  // 空=框架自动拼接 prefix+entityName
```

## 四、代码生成器

### 4.1 概述

**位置：** `isass-nocode-core/src/main/java/vip/isass/framework/nocode/v3/generator/V3MybatisPlusGenerator.java`

**模板：** `isass-nocode-core/src/main/resources/v3Template/`

### 4.2 生成清单（8 个文件）

| # | 文件 | 模板 | 说明 |
|---|------|------|------|
| 1 | `V3{Entity}.java` | `entity.java.ftl` | 纯净 POJO（实现 IV3* 接口，无 ORM 注解） |
| 2 | `V3{Entity}Criteria.java` | `criteria.java.ftl` | 查询条件 |
| 3 | `V3{Entity}Mapper.java` | `mapper.java.ftl` | MyBatis-Plus Mapper（`extends BaseMapper<V3Entity>`） |
| 4 | `V3{Entity}Mapper.xml` | `mapper.xml.ftl` | XML 映射 |
| 5 | `V3{Entity}Repository.java` | `repository.java.ftl` | 数据仓库（`V3MybatisPlusRepository<E,C,M>` 3 泛型参数，去 EDB） |
| 6 | `IV3{Entity}Service.java` | `IService.java.ftl` | 服务接口 + 内嵌 ServiceManager |
| 7 | `V3{Entity}Service.java` | `localService.java.ftl` | 本地服务实现 |
| 8 | `V3{Entity}FeignService.java` | `feignService.java.ftl` | Feign 远程调用 |

> v2 的 `entityDb.java.ftl`、`controller.java.ftl` 在 v3 中已删除。
> 模板包名已从旧 `vip.isass.core.structure.*` 修正为 `vip.isass.framework.nocode.v3.*`。
> Mapper 模板已从 `IMapper` 改为 MyBatis-Plus 原生 `BaseMapper`。
> `V3MybatisPlusRepository` 类签名从 v2 的 `(E, EDB, C, M)` 重写为 `(E, C, M extends BaseMapper<E>)`，Entity 直接操作 MyBatis-Plus（无 EDB 转换、无 Convert、无 `fillV3EntityProperties`）。

## 五、API 端点

以 `/{serviceName}/v3/{entityName}` 为前缀，36 个端点与 v2 操作集一致。示例：

| 方法 | URI | 说明 |
|------|-----|------|
| `POST` | `/attachment-service/v3/icon` | 新增 |
| `GET` | `/attachment-service/v3/icon/all` | 查询全部 |
| `GET` | `/attachment-service/v3/icon/page` | 分页查询 |
| `GET` | `/attachment-service/v3/icon/1` | 按 ID 查询 |
| `PUT` | `/attachment-service/v3/icon/1` | 按 ID 更新 |
| `DELETE` | `/attachment-service/v3/icon/1` | 按 ID 删除 |
| `GET` | `/attachment-service/v3/icon/criteria?name=foo` | 条件查询 |

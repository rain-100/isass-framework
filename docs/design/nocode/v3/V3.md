# nocode v3 设计

## v3 与 v2 的核心区别

v2 中，Controller (`IV2Controller`) 放在 `isass-web-springmvc`，ORM 实现 (`V2MybatisPlusRepository`) 放在 `isass-database-mybatisplus`。业务微服务需要同时依赖这三个模块。

v3 遵循 **nocode 整合层** 的设计原则：`isass-nocode-core` 作为唯一的 nocode 入口，同时承载 Controller 和 ORM 实现，封装 Spring MVC + MyBatis-Plus 为统一的无代码编程体验。业务微服务只需依赖 `isass-nocode-*`。

## 模块职责

| 模块 | 角色 | 内容 |
|------|------|------|
| `isass-nocode-core` | **nocode 整合层** | IV3Entity/IV3Service/IV3Controller/V3MybatisPlusRepository 等全部定义和实现 |
| `isass-web-springmvc` | MVC 基础设施 | 拦截器、异常处理、RestTemplate 等，不包含 nocode 业务 |
| `isass-database-mybatisplus` | ORM 基础设施 | Mapper/TypeHandler/配置等，不包含 nocode 业务 |

## v3 包结构

```
isass-nocode-core/src/main/java/vip/isass/framework/nocode/v3/
├── entity/          # 实体接口层（IV3Entity, IV3IdEntity, IV3TraceEntity...）
├── criteria/        # 查询条件层（IV3Criteria, V3WhereCondition...）
├── service/         # 服务层（IV3Service, IV3LocalService, V3ServiceManagerUtil...）
├── repository/      # 数据访问层（IV3Repository）
├── controller/      # Spring MVC 控制器（IV3Controller）
├── orm/             # MyBatis-Plus ORM 实现（V3MybatisPlusRepository, V3WrapperUtil...）
├── entrypoint/      # 入口接口
├── converter/       # 类型转换器
└── util/            # 工具类（V3BatchUtil, V3TreeEntityUtil）
```

## v2 → v3 迁移

- 类名：`IV2*`/`V2*` → `IV3*`/`V3*`
- 包名：`nocode.v2.*` → `nocode.v3.*`
- Controller 从 `web-springmvc` 迁入 `nocode-core`
- MyBatis-Plus 实现从 `database-mybatisplus` 迁入 `nocode-core`
- `IMapper` 替换为 MyBatis-Plus 原生 `BaseMapper`（避免循环依赖）
- 代码生成器留待后续实现

# 模块号和端口号

- 模块是指不能以 http 服务(或其他服务形式) 启动的项目模块，例如 isass-framework、isass-api 的各个子模块
- 端口号是指微服务的端口号
- 合理分配模块号和端口号，避免重复冲突
- 抛异常时，接口返回状态码给前端，状态码字段设置为模块号或者端口号，从而快速识别异常来源

## 模块号分配规则
10000~10999：分配给 isass-framework 的模块
11000~11999：分配给 isass-api 的模块
12000~14999：isass 预留模块

15000~19999：分配给其他公司的模块

## 端口号分配规则
20000~24999：分配给 isass 本身的微服务
25000~29999：分配给其他公司开发的微服务

每套服务预占用10个，0~5给后端，5~9给前端
例如
权限微服务，用20040~20049，0~5给后端，5~9给前端
20040：后端进程http端口
20041：后端socketio端口
20042：后端远程调试端口
20043：后端jmx端口
20045：前端pc端
20046：前端xx大屏端
20047：前端xx平台
20048：前端xx系统
20049：前端xx端
